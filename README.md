# multirate-filter
Hey buddy! 👋

This project demonstrates the simulation of a Multirate FIR Filter on an Artix-7 FPGA architecture using Xilinx Vivado.

Just extract the downloaded ZIP file, open Vivado, and select the extracted project (`project_1.xpr`). Then run **Behavioral Simulation** under the Simulation section. You'll be able to see the waveforms.

Give it a try! 😊
